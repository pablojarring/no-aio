# Código de conducta / Code of Conduct

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: trata a todos con respeto, sin acoso ni ataques personales, y critica ideas, no personas. Los mantenedores pueden editar o eliminar contribuciones que no cumplan estas normas.

Para reportar un problema de conducta, usa **Security → Report a vulnerability** en el repositorio y escribe "conduct" en el título.
