# Seguridad / Security

Si encuentras una vulnerabilidad, no abras un issue público. Usa **Security → Report a vulnerability** en este repositorio (GitHub private vulnerability reporting).

If you find a vulnerability, please don't open a public issue. Use **Security → Report a vulnerability** on this repository.

No AIO no hace peticiones de red, no ejecuta código remoto y no guarda más que tres ajustes locales.
