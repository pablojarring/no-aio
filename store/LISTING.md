# Store listing: textos para pegar

Configura **inglés** como idioma por defecto y agrega como traducciones **español, alemán, ruso, japonés e hindi**. En la ficha de cada idioma sube sus 4 capturas `screenshot-1..4-<lang>.png`. Las dos imágenes promocionales son universales. Todas las imágenes son PNG de 24 bits sin alfa, como pide la tienda. Códigos: `en`, `es`, `de`, `ru`, `ja`, `hi`.

| Campo | Valor |
|---|---|
| Categoría | Productivity → Tools *(alternativa: Make Chrome Yours → Functionality)* |
| Ícono de la tienda | `assets/store-icon-128.png` |
| Promo tile pequeño (440×280) | `assets/promo-small-440x280.png` (universal, una para todos los idiomas) |
| Marquee (1400×560, opcional) | `assets/promo-marquee-1400x560.png` (universal) |
| Capturas (1280×800) | `assets/screenshot-1/2/3/4-<lang>.png` |
| Sitio web oficial | `https://github.com/pablojarring/no-aio` |
| URL de soporte | `https://github.com/pablojarring/no-aio/issues` |
| Política de privacidad | `https://pablojarring.github.io/no-aio/privacy/` |

El nombre y la descripción corta los toma la tienda de `_locales/*/messages.json`, así que ya están traducidos.

## English: detailed description

```
No AIO removes Google's AI Overview from your search results, so the links you came for are back at the top of the page.

Google doesn't offer a setting to turn AI Overviews off. No AIO gives you that switch.

TWO MODES
• Hide (default): you keep the normal "All" results — images, videos, "People also ask", the side panel — and only the AI Overview block disappears.
• Web (udm=14): every search opens Google's own Web filter, so the AI summary is never generated. Plain blue links, no shopping blocks. Turned off by default; you enable it from the popup.

ALSO
• Optionally hides the "AI Mode" tab.
• Works on every Google Search domain (google.com, google.es, google.com.mx, google.com.ec…).
• Detects the AI block by its title, not by Google's obfuscated class names, so it is more resilient to layout changes.

PRIVACY FIRST
• Collects no data. Sends nothing anywhere. No analytics, no ads, no remote code.
• Only runs on Google Search result pages.
• Your 3 settings are stored with Chrome sync storage.

OPEN SOURCE
MIT licensed. Read the code, report a bug or add your language:
https://github.com/pablojarring/no-aio

Made by Oniria. Not affiliated with or endorsed by Google. "Google" is a trademark of Google LLC.
```

## 日本語：詳細な説明

```
No AIO は Google の「AI による概要」を非表示にし、探していたリンクを再びいちばん上に表示します。

Google には AI による概要をオフにする設定がありません。No AIO がそのスイッチになります。

2 つのモード
• 非表示（デフォルト）：通常の検索結果ページ（画像、動画、「関連する質問」、サイドパネル）はそのまま。AI のブロックだけを消します。
• ウェブ（udm=14）：すべての検索を Google のウェブフィルタで開くため、AI の要約は生成されません。リンクのみで、ショッピング枠もありません。初期状態はオフで、ポップアップから有効にできます。

その他
• 「AI モード」タブも非表示にできます。
• すべての Google ドメイン（google.co.jp、google.com など）で動作します。
• Google の変わりやすい CSS クラスではなく、見出しで AI ブロックを検出します。

プライバシー
• データを一切収集・送信しません。分析、広告、リモートコードはありません。
• Google 検索の結果ページでのみ動作します。

オープンソース
MIT ライセンス：https://github.com/pablojarring/no-aio

開発：Oniria。Google とは提携していません。「Google」は Google LLC の商標です。
```
